
## Project Description
This is a one page website for Per Scholas SBA2. It shows a responsive and accessible layout using plain HTML,CSS, and JavaScript. The pafe has a header with a menu that collapses on phones, an About section, a service section with three cards, and a Contact from that checks your input before it sedds. It works with a keyboard and screen reader, and it fits any screen size.
## How to View it
1.download or clone this folder.

2.open the folder and douple click index.html.

3.The page opens in your browser. That's it, nothing to install.
